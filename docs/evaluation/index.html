Evaluation

tididi-cnf and other exact solvers ran on the instances of the Model Counting Competition's track 1, unweighted model counting, from 2025 and 2026: each solver on each instance, on one machine under the same limits. Every count but one agrees with the count of each other solver that finished the same instance, and that one counts as not solved. How it was measured names the solvers' versions, the machine and the limits. tididi-cnf also runs in the browser.
