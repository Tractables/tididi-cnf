How well does it work?

tididi-cnf is a bottom-up CNF compiler. Compare its reusable diagrams with bottom-up decision-diagram compilers, then compare saved circuits with logic-circuit compilers and model counting. All three primary comparisons use the same 1,400 track-1 entries of the Model Counting Competition from 2020–2026, with the same input representatives and two minutes per instance. Historical subsets remain available as supplements. How it was measured names the source snapshot, representative inputs, solvers, machines and limits, and records failed invocations. tididi-cnf also runs in the browser.
